# Asset Provenance

All gameplay visuals are rendered programmatically with geometric primitives in the Compose UI layer. No downloaded bitmap, font, illustration, sprite sheet, or traced third-party artwork is used.

Launcher icons and PCM audio are original deterministic assets generated by:

```bash
python tools/generate_assets.py
```

The generator:

- uses only the Python standard library
- draws geometry directly into PNG scanlines
- synthesizes audio from mathematical waveforms
- does not download, sample, trace, or embed third-party material
- supports isolated output through `MSA_BEE_ASSET_ROOT`

Generated files include Android launcher icons, the iOS App Store icon, and the four bundled WAV files: background music, jump, score, and game-over cues.

Exact SHA-256 values are recorded in `ASSET_MANIFEST.sha256`. Verify byte-for-byte reproducibility with:

```bash
python scripts/verify_generated_assets.py
```

Generated assets are covered by the project license in `LICENSE.md`.

## Desktop package icons

The Windows ICO, macOS ICNS, and Linux PNG package icons are deterministically generated from the same project-owned bee artwork. The ICO and ICNS containers are written directly by the Python standard-library generator and structurally validated by `scripts/verify_project.py`.
